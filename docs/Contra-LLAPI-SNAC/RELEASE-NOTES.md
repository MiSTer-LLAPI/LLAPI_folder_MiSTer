# Contra Enhanced v0.8.0
LLAPI Enhanced v0.3.0-dev supports two players. SHOOT and JUMP remain independent. Enable HOLD for either player in Autofire. Both start Off. Replacing a controller clears autofire for that port.
The Controller Guide shows the selected interface and shortcuts. SNAC supports Saturn, Mega Drive, DB15, SNES, PCE and NES with suitable adapters. LLAPI waits for previously connected players and counts down before resuming.
